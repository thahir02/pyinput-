Rules to assign the variable names
  1. You should start variable name with an alphabet or undersore(_) character.
  2. A variable name can only contain A-Z,a-z,0-9, and underscore(_).
  3. You cannot start the variable name with a number.
  4. You cannot use special characters with the variable name such as $,%,#,&,@,etc.
  5. Variable names are case sensitive.For example str and Str are two different variables.
  6. Do not use revserve keyword as a variable name For example keywords like class,for,def,type,etc..,
